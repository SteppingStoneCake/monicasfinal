# New Orleans, My Kind of City

A responsive New Orleans travel page for Monica Privett's final web project. It demonstrates a hero, footer, cards, CSS Grid layouts, two iframe embeds, CSS image filters, and a semantic HTML table.

The French Quarter, Garden District, jazz park, Frenchmen Street, and streetcar ideas link to New Orleans & Company, the National Park Service, and the New Orleans Regional Transit Authority. The illustration and embedded postcard are original project assets. The map requires an internet connection.

Open `index.html` or serve the folder with `python3 -m http.server 8000`. In Netlify, import the public `SteppingStoneCake/monicasfinal` repository; its root `netlify.toml` sets `new-orleans-travel` as the publish directory. No build command is needed.
