# Monica Privett — Creative Portfolio

A responsive, multi-page HTML/CSS/JavaScript portfolio for the SheCodes final project. It includes a hero, footer, cards, CSS Grid layouts, a local iframe embed, visible CSS filter comparisons, and a semantic HTML table.

## Preview locally

Run `python3 -m http.server 8000` from this directory and open `http://localhost:8000`.

## Publish

This site lives in the `monica-creative-portfolio/` folder of the public [`SteppingStoneCake/monicasfinal`](https://github.com/SteppingStoneCake/monicasfinal) repository. In Netlify, import that repository and use `monica-creative-portfolio` as the publish directory; no build command is needed. The footer and homepage link to the repository. Once Netlify assigns the live URL, add canonical metadata and a sitemap for that exact domain.

The GitHub projects page requests public repositories for `SteppingStoneCake` from the GitHub API. The font import and GitHub feed need network access; core content and the embedded postcard work locally.
