# Monica Creative Portfolio

Multi-page static portfolio for Monica Privett.

Includes Home, About, Studio, Creative Work, Perfume, TTRPG, Development, GitHub, Now Creating, Creative Timeline, and Contact pages.

GitHub integration uses the public GitHub REST API to load repositories for `SteppingStoneCake` in the browser.

Before publishing:
1. Replace `https://example.com/` in canonical URLs, robots.txt, and sitemap.xml with the final Netlify/custom-domain URL.
2. Replace the placeholder email on contact.html.
3. Add portfolio images to `assets/images/`.
